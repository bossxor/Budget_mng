# 주머니 v1.8.0

- 범용 규칙이나 추측으로 읽은 알림은 확인 전 후보로 보관합니다. 승인 전에는 수입·지출 합계, 예산, 위젯, 결산, 정산에 넣지 않습니다.
- 안내형 알림 도우미에서 출처·원문·금액·추천 분류를 보고 맞아요, 고쳐서 맞아요, 아니에요와 이유를 답할 수 있습니다.
- 거래 여부 판독과 적금·카드대금 등의 분류를 별도로 학습합니다. 확인한 정답과 오답을 휴대폰 안에서 다음 제안에 활용합니다. 불확실하거나 상충하는 사례는 다시 확인합니다.
- 대화방/앱 숨김, 광고·인증 오답 학습, 중복 기록 연결, 내 계좌 이체 확정을 지원합니다. 설정의 숨긴 알림에서 규칙 해제와 답변 되돌리기를 할 수 있습니다.
- 등록한 금융·문자 출처는 숨김 규칙에서 보호합니다. 과거 미승인 범용 기록은 원문 일치를 확인해 후보로 재검토하며 사용자 승인·정산·연결 이체는 보존합니다.
- 새 학습 결과는 확인용 제안입니다. 모델 판단만으로 임의 확정하거나 숨기지 않습니다.

데이터 변경: 기존 테이블을 유지하고 알림 출처 열, 피드백·숨김 규칙 테이블을 추가합니다. 기존 암호화 백업에 피드백과 규칙을 포함하며 되돌린 규칙의 복원 충돌을 방지합니다.
