# 주머니 v1.9.0 · 패턴 학습과 자동 반영

- 확인 화면에 패턴별 진행 상황과 자동 반영 전환 조건을 표시합니다.
- 같은 패턴 최근 10건 중 9건 이상 제안 일치, 최근 5건 연속 수정 없음이면 자동 반영을 제안합니다. 사용자가 허용한 뒤 적용합니다.
- 확실한 패턴은 현재 거래를 확인하면서 바로 자동 반영 대상으로 지정할 수 있습니다.
- 설정에서 패턴을 켜거나 일시중지할 수 있고, 자동 반영 내역을 수정·되돌리면 해당 패턴을 멈춥니다.
- 자동 처리 결과를 스스로 정답으로 학습하지 않습니다. 기존 학습은 유지하고 새 추천 확인 결과부터 전환 기준을 집계합니다.
- 백업에 패턴과 확인 결과를 보존하며, 복원한 활성 패턴은 범위를 다시 확인한 뒤 켤 수 있도록 일시중지합니다.
