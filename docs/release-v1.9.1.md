# 주머니 v1.9.1 · 어떤 알림에서 생긴 내역인지 확인

- "이미 기록된 거래예요"를 고를 때 같은 거래 후보를 카드로 보여 줍니다. 시각, 제목, 금액에 더해 계좌, 카테고리, 출처 앱, 그 거래를 만든 알림 원문(최대 3줄)이 나옵니다. 직접 입력한 내역은 "직접 입력"으로 표시합니다.
- "확인이 필요한 내역" 목록의 각 항목에 출처 앱과 알림 원문을 한 줄 더 보여 줍니다.
- "인식 못 한 알림"의 출처를 패키지 이름 대신 앱 이름으로 표시합니다.
- 원문 보관 기간이 지났거나 백업에서 복원해 원문이 없는 내역은 출처 없이 기존처럼 표시합니다.
