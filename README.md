# 주머니 (Budget_mng)

알림으로 자동 수집하는 개인용 Android 가계부. **더치페이 정산**과 **통장별 목적 관리**가 핵심입니다.

- 작업물 모음: [bossxor 작업물 대시보드](https://bossxor.github.io/works-dashboard/)
- 설계 문서: [DESIGN.md](DESIGN.md)

## 다운로드

[최신 릴리스](https://github.com/bossxor/Budget_mng/releases/latest)에서 APK를 받아 설치합니다.

1. 폰에서 "출처를 알 수 없는 앱 설치"를 허용합니다.
2. 설치 후 앱을 열고 **설정 > 알림 접근**에서 주머니를 켭니다.
3. 설정에서 **내 이름**을 입력하면 본인 계좌 간 이체를 지출에서 자동으로 뺍니다.

> Android 전용입니다. 알림을 읽는 방식이라 iPhone에서는 쓸 수 없습니다.

## 기능

**수집**
- 카드·은행·토스 알림을 읽어 지출/입금을 자동 기록 (서버 없음, 데이터는 폰 안에만 저장)
- 앱이 꺼져 있어도 알림이 오면 바로 거래로 변환
- 광고·마케팅 알림은 저장하지 않음 (금융 키워드가 있는 알림만)
- 설정에서 다른 은행 앱을 골라 알림 수집 대상에 추가
- 잔액이 이어지지 않으면 "알림이 빠진 것 같아요"로 알려 줌

**가계부**
- 내 계좌 간 이체와 모임통장은 지출/수입에서 제외, 가맹점은 규칙으로 자동 분류하고 수정하면 학습
- 날짜별 내역, 월말 결산(전월 비교·Top 5), 검색/태그, 결제 카테고리 나누기
- 거래 직접 수정(이름·금액·날짜·메모), 카테고리 추가, CSV 내보내기(엑셀)
- 한 달 예산·카테고리 예산, 하루 사용 가능 금액, 고정지출(구독 등) 자동 감지
- 인식 못 한 알림은 눌러서 금액이 채워진 채로 바로 내역으로 만들기
- 앱 아이콘을 길게 눌러 "직접 입력" 바로가기

**더치페이 정산**
- 결제를 골라 N등분 또는 사람별 금액으로 나누고, 입금 알림을 정산에 연결 (분할·합산 입금)
- 다른 사람이 낸 결제도 넣으면 사람별 순액(받을 돈/보낼 돈)을 계산, 보낸 송금을 연결해 정리
- 자주 만나는 멤버를 모임으로 저장, 3일 지나도 못 받은 돈은 홈에서 다시 요청 (요청 문구 편집 가능)
- 정산한 결제는 내 몫만 지출로 반영, 입금은 수입에서 제외
- 이름이 같거나 금액이 딱 맞는 입금을 홈에서 한 번에 연결하도록 추천

**통장 목적 관리**
- 생활비/적금/여행비/공과금 등 역할별 통장, 잔액, 월 배분 계획 이행 체크
- 저축/인출 집계와 저축률, 목표 금액·기한별 진행률, 카드 결제 통장 연결

**보안·데이터**
- 앱 잠금(PIN 6자리 + 지문/얼굴), 최근 앱 화면 가림
- 암호화 백업/복원(AES-256-GCM), 알림 원문 보관 기간 설정
- 글자체 선택(Noto Sans KR 기본, Pretendard·나눔스퀘어는 앱에 포함), 글자 크기 조절

## 지원하는 알림

| 수집원 | 형식 |
|---|---|
| 삼성카드 (카카오톡 알림) | 승인/취소/할부 |
| 카카오뱅크 | 입금/출금 푸시 |
| 부산은행 문자 | 입금/출금 |
| 토스 | 입금/출금, 모임통장 출금 안내 |

다른 은행/카드는 `lib/core/parsers.dart`에 정규식 템플릿을, `parser_samples.json`에 샘플을 추가하면 됩니다.
샘플은 가명 처리한 값만 저장소에 올리고, 실제 알림은 `samples.local/`(git 제외)에서만 사용합니다.

## 개발

```bash
flutter pub get
flutter test                 # 파서·정산·통장·백업 로직 테스트
flutter build apk --release
```

- Flutter + Kotlin(`NotificationListenerService`), 로컬 SQLite(sqflite)
- 알림 원문은 기기 내부 `budget.db`에만 저장되며 외부로 전송되지 않습니다.
- Windows 네트워크 드라이브에서는 Gradle 빌드가 실패할 수 있으니 로컬 디스크에서 빌드하세요.
- 디버그 빌드에서는 `adb shell cmd notification post`로 보낸 테스트 알림도 수집합니다 (릴리스 빌드에서는 무시).
