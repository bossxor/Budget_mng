# 주머니 (Budget_mng)

알림으로 자동 수집하는 개인용 Android 가계부. **더치페이 정산**과 **통장별 목적 관리**가 핵심입니다.

- 카드·은행·토스 알림을 읽어 지출/입금을 자동 기록 (서버 없음, 데이터는 폰 안에만 저장)
- 내 계좌 간 이체와 모임통장은 지출/수입에서 제외, 가맹점은 규칙으로 자동 분류하고 수정하면 학습
- 더치페이: 결제를 골라 N등분/개별 금액으로 나누고, 입금 알림을 정산에 연결 (분할·합산 입금, 내 몫만 지출 반영)
- 통장을 생활비/적금/여행비/공과금 등 목적별로 관리: 잔액, 월 배분 계획 이행 체크, 저축률, 목표 진행률
- 앱 잠금(PIN + 생체인증), 글자체 선택

설계 문서는 [DESIGN.md](DESIGN.md), 알림 파서 샘플은 [parser_samples.json](parser_samples.json)(가명 처리)에 있습니다.

## 지원하는 알림

| 수집원 | 형식 |
|---|---|
| 삼성카드 (카카오톡 알림) | 승인/취소/할부 |
| 카카오뱅크 | 입금/출금 푸시 |
| 부산은행 문자 | 입금/출금 |
| 토스 | 입금/출금, 모임통장 출금 안내 |

다른 은행/카드는 `lib/core/parsers.dart`에 정규식 템플릿과 `parser_samples.json`에 샘플을 추가하면 됩니다.

## 개발

```bash
flutter pub get
flutter test            # 파서·정산·통장 로직 테스트
flutter build apk --debug
```

- Android 전용 (알림 리스너 `NotificationListenerService` 사용). 설치 후 설정에서 **알림 접근**을 허용해야 합니다.
- 알림 원문은 기기 내부 SQLite(`budget.db`)에만 저장되며 외부로 전송되지 않습니다.
- Windows 네트워크 드라이브에서는 Gradle 빌드가 실패할 수 있으니 로컬 디스크에서 빌드하세요.
